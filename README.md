## 🛠️ Teknologi Website Ini

Website portofolio ini dibangun dengan pendekatan **Pure/Vanilla Web Technologies** untuk memastikan performa yang cepat dan kompatibilitas yang luas tanpa ketergantungan framework berat.

* **HTML5 Semantic:** Struktur dokumen yang rapi dan mudah dibaca mesin pencari.
* **CSS3 Glassmorphism:** Desain UI modern dengan efek transparansi dan blur (`backdrop-filter`).
* **JavaScript (ES6):** Mengatur interaksi pengguna, seperti menu Accordion yang responsif.
* **FontAwesome:** Integrasi ikon vektor untuk visual yang menarik.
* **Responsive Design:** Tampilan otomatis menyesuaikan untuk Desktop maupun Mobile (tampilan kartu nama digital).

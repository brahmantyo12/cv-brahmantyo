## 🛠️ Teknologi yang Digunakan
Project ini dibangun menggunakan "Vanilla" Web Technologies tanpa framework berat, untuk menjaga performa tetap ringan dan cepat.

* **HTML5:** Semantik markup untuk struktur konten.
* **CSS3:**
    * **Glassmorphism UI:** Menggunakan `backdrop-filter: blur()` dan transparansi.
    * **Flexbox:** Untuk layout yang responsif.
    * **Animations:** Transisi halus pada hover dan accordion.
* **JavaScript (ES6):**
    * Logika **Accordion** untuk membuka/menutup panel pengalaman dan skill.
    * DOM Manipulation.
* **FontAwesome:** Ikon vektor untuk visual yang menarik.
* **Google Fonts:** Tipografi menggunakan font 'Poppins'.
